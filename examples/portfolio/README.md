# HALO meeting workspace

Serve this folder with `python -m http.server 8000 --directory examples/portfolio` from the repo root, then open http://localhost:8000.

Run `node --test examples/portfolio/model.test.mjs` for retrieval and sentence checks. Install Playwright and its Chromium browser, then run `python tools/browser_audit.py` for end-to-end interactions.
